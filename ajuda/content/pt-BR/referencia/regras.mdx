# Regras de negócio

Cada comportamento do ITS vem de uma regra de negócio numerada, como a RN-05. Aqui estão todas, em linguagem simples, cada uma com um link para a página onde você a vê funcionando.

No texto da Ajuda, a regra aparece como uma palavra ou um trecho com link, como em "ao não autorizar uma ideia, <Regra id="RN-05">a justificativa vai para quem enviou</Regra>". O link traz você para a regra, nesta página.
